About QuickNotes

QuickNotes is a minimal, fast note-taking application designed to help you capture ideas instantly without distractions.

How to use QuickNotes

  1. Go to the Home page and type your note in the input field.
  2. Click Save to add your note to the list.
  3. Manage your notes by editing or deleting them when needed.

Features

  • Fast and lightweight
  • Works offline
  • Simple and clean design

Keyboard Shortcuts

Shortcut Action
Ctrl + N Create new note
Ctrl + S Save current note
Ctrl + D Delete selected note
